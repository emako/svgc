# Agent guidelines

## Git commit messages

- Subject is the first line only; keep it imperative and concise (about 50–72 chars).
- **Do not end the subject with trailing punctuation**, including `.` `。` `!` `？` `?` `,` `;` `…` or similar.
- Prefer `fix X` / `add Y` / `update Z` over wrapping sentences that need a period.

```text
# ❌ BAD
Initial commit: add svgc Rust CLI with SVG conversion and CI build.

# ✅ GOOD
Initial commit: add svgc Rust CLI with SVG conversion and CI build
```
